# 김은혜 포트폴리오 웹사이트

Figma 인트로 시안을 기준으로 만든 1차 버전입니다. WebDesign / PrintDesign / CharacterDesign / InteriorDesign(3D) 섹션은
"준비 중" 상태의 자리만 잡아두었고, 작업물이 준비되는 대로 채워 넣으면 됩니다.

## 파일 구성
- index.html – 페이지 본문
- style.css – 디자인/레이아웃
- script.js – 스크롤 시 메뉴 활성화 효과

## GitHub Pages로 배포하는 방법 (계정이 없는 경우)

1. https://github.com 접속 → 우측 상단 **Sign up** → 이메일/비밀번호/아이디로 계정 생성 (이메일 인증 필요)
2. 로그인 후 우측 상단 **+** 버튼 → **New repository** 클릭
3. Repository name에 `portfolio` 등 원하는 이름 입력 (Public으로 설정) → **Create repository**
4. 저장소 페이지에서 **uploading an existing file** 링크 클릭
5. 이 폴더 안의 index.html, style.css, script.js 세 파일을 그대로 끌어다 놓기(drag & drop) → **Commit changes**
6. 저장소 상단 **Settings** 탭 → 왼쪽 메뉴 **Pages** 클릭
7. **Branch**를 `main`(또는 `master`), 폴더는 `/root`로 두고 **Save**
8. 1분 정도 기다리면 같은 화면에 아래와 같은 형태의 주소가 표시됩니다.

```
https://아이디.github.io/portfolio/
```

이 주소를 명함에 넣으시면 됩니다. 이후 실제 작업물이 준비되면 같은 저장소에 파일만 다시 업로드(덮어쓰기)하면
주소는 그대로 유지된 채 내용만 업데이트됩니다.
